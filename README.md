# 🎬 MyFlix - Private Streaming Platform

MyFlix is a private video streaming interface built using simple HTML, CSS, and JavaScript. It allows users to stream Google Drive-hosted videos through embedded previews and even add new movies on the fly directly from the UI. Ideal for small, personal use cases such as home media libraries or peer sharing (not intended for public or commercial use).

---

## 🔥 Features

- 🎥 Clean and modern UI for private video streaming
- 📼 Supports embedded Google Drive video previews
- 🖥️ Responsive grid layout with smooth animations
- 🔍 Built-in "Stream Checker" redirect for future enhancements
